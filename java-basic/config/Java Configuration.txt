TODO. Windows配置系统环境变量
1. 新建 JAVA_HOME=C:\Program Files\Java\jdk-17.0.9
2. 环境变量 PATH路径添加 %JAVA_HOME%\bin
> java -version
> echo %JAVA_HOME%
> echo %PATH%

TODO：MacOS环境配置: 设置JAVA_HOME和PATH
ZSH 配置到.zshrc文件
export PATH="/xxx/Java/jdk-xxx.jdk/Contents/Home/bin:$PATH"
export JAVA_HOME="/xxx/Java/jdk-xxx.jdk/Contents/Home"
> source ~/.zshrc
> java -version

TODO: Linux环境配置: 服务器可配置不同JDK版本
> tar zxvp xx.tar 下载JDK并解压到特定目录
> sudo gedit /etc/profile 添加环境变量到profile文件
  export JAVA_HOME="/usr/local/java/jdk-17.0.2"
  export PATH=$JAVA_HOME/bin:$PATH
> source /etc/profile 再编译, 立即执行更新
> sudo apt-get update
> sudo apt install openjdk-8-jdk
