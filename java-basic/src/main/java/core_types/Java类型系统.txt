TODO. Java 类型系统
Primitive type 原生类型 (直接存值的类型)
  - 原生类型都有对应的Wrapper包装类(对应的引用类型)
  - 包装类存在null值异常
  - 装箱类型的比较应该调用.equals()
Reference type 引用类型 (String, List, Class, Interface, Array..)
  - 引用类型支持Null值(默认值)
